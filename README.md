## 📌 Ключевой проект

### 🔹 Job Board API (Mini HeadHunter)

Полноценный backend-сервис для публикации вакансий и откликов.

**Стек:** FastAPI • Async SQLAlchemy • PostgreSQL • Alembic • Docker

**Функциональность:**

* JWT-аутентификация (user / company / admin)
* Компании и профили работодателей
* CRUD вакансий (только владелец или admin)
* Отклики пользователей (без дублей)
* Фильтрация и пагинация вакансий
* Ролевая система доступа
* Асинхронная архитектура
* Swagger документация
* Docker-развертывание одной командой
* Миграции Alembic
* Тесты (pytest)
* CI через GitHub Actions

**Запуск:**

```bash
docker compose up --build
```

Swagger:

```
http://localhost:8000/docs
```
